# Figure sources

* `figure1_left_infographic.svg` - the hand-made vector drawing of the olfactometer and the participant (left side of Fig. 1; labels A-I as in the legend), edited in Inkscape. All text and shapes are outlines.
* `figure1_left_infographic.pdf` - its export (Inkscape: File > Save a Copy > PDF). `scripts/make_fig1.py` places this PDF, unchanged, next to the respiration trace and writes `figures/fig1.pdf`.
  If you edit the drawing, re-export the PDF (a test checks that the two have the same proportions).
* `figure1_left_infographic_live_text.svg` - an earlier version of the same drawing with editable text.
